# University Examination Analytics Platform

## Project Overview

A Data Engineering project that automates examination result processing using Python, PostgreSQL and SQL Analytics.

## Architecture

CSV Files
 ↓
Python ETL
 ↓
Data Validation
 ↓
PostgreSQL
 ↓
SQL Analytics

## Features

- Student Data Processing
- Marks Transformation
- Pass/Fail Calculation
- Data Quality Checks
- PostgreSQL Data Storage
- Performance Analytics

## Technology Stack

- Python
- Pandas
- PostgreSQL
- SQLAlchemy
- SQL
- Git

## Analytics

- Pass Percentage
- Department Performance
- Top Performers
- Gender-wise Analysis
